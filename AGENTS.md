# Agent Guidelines & Workflow Rules

## Git & Version Control
- **No Automatic Commits or Pushes**: You MUST NEVER stage, commit, or push files to Git automatically without explicit developer confirmation.
- **Review in Working Tree**: All generated code, documentation, and edits must remain in the working directory for user inspection.
- **Explicit Instruction Required**: Only execute `git commit` or `git push` when the user explicitly requests it.
